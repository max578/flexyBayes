flexyBayes · walkthrough · read in 10, reproduce in 30

Two readings of a sleep-deprivation study

A scientist has a question and a small, real data set. A methodologist fits it three different ways and checks they agree. You can run every line below.

Data: sleepstudy (Belenky et al., shipped with lme4) — average reaction time over days of restricted sleep, 18 subjects, 180 observations. Public, citable, tiny.

The path The question  ·  One formula  ·  Three engines  ·  Triangulation  ·  Reproduce it

The question

Dr. Okafor (sleep scientist). “Each night my subjects were held to three hours in bed. Their reaction times drift upward day by day — but every person starts in a different place and some degrade faster than others. I want the population effect of a lost day of sleep, with calibrated uncertainty, without pretending all 18 people are interchangeable.”

Ravi (methodologist). “That is a linear mixed model: a population slope for Days, plus a per-subject intercept so each person keeps their own baseline. The classical fit is one line of lme4. But you asked for uncertainty as a full distribution — that is the Bayesian reading. flexyBayes lets us write the model once and get both.”

One formula

library(flexyBayes)
data(sleepstudy, package = "lme4")

fit <- flexybayes(
  fixed  = Reaction ~ Days,   # the population effect Dr. Okafor wants
  random = ~Subject,          # each subject keeps their own intercept
  data   = sleepstudy,
  backend = "inla"
)
coef(fit)

Ravi. “fixed is the mean structure — reaction time as a function of days. random = ~Subject is the partial-pooling part: we do not estimate 18 unrelated intercepts, we treat subjects as draws from a population, which stabilises the per-person estimates and gives a clean population slope.”

Three engines, one answer

The only thing that changes is backend =. Each routes the same formula through a different estimation machine. Here is what they return for the slope — the rise in reaction time per lost day of sleep — alongside the classical lme4 reference:

How it was fitDays slope (ms/day)What it tells us
backend = "inla"10.451fast, deterministic; identical to a hand-written INLA fit
backend = "greta"10.533TensorFlow HMC (sampling)
backend = "brms"10.48Stan HMC; matches a standalone brms fit (10.43)
lme4::lmer10.467frequentist REML, the textbook reference

Dr. Okafor. “They all say about ten and a half milliseconds per day.”
Ravi. “Three different Bayesian samplers and the classical estimator, all landing in the same place. That is the cross-paradigm agreement you want before you put a number in a paper.”

When an engine hedges. The greta run reported that its sampler had not fully converged at this warm-up (R-hat above 2). The estimate was still in range, but for a final result we would raise warmup and re-check. The convergence diagnostic is reported alongside the estimate.

Triangulation as evidence

Ravi. “Because we can fit the model three ways, agreement between the engines is itself evidence. A fast deterministic engine (INLA) and a gold-standard sampler (Stan) reaching the same posterior means neither is fooling us. flexyBayes calls this triangulate(); on a real analysis it is how I decide a result is trustworthy enough to ship — and how flexyBayes scales: prototype in INLA, confirm in Stan.”

Reproduce it

Every number above is computed by the validation benchmarks — none is hand-typed. From the report folder:

# requires R with: flexyBayes (dev), lme4, INLA, greta, brms
cd validation
Rscript bench/fb-inla-correctness.R     # the INLA fit + standalone-INLA + lme4 (seconds)
Rscript bench/fb-greta-correctness.R    # the greta/TF-HMC fit vs lme4   (~1 minute)
Rscript bench/fb-brms-correctness.R     # the brms/Stan fit + standalone brms + lme4 (~20s after compile)

Each writes a cached result the validation cards read, so the numbers you see are always the numbers a run produced. The full evidence index is validation/ai/evidence.json; the conceptual background is the tutorial.

Data: the sleepstudy data set distributed with the lme4 R package (Belenky et al., 2003, sleep-restriction reaction-time study). flexyBayes figures reproduced from ../validation/.
